## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebPollerThread → orchestrator._web_poller | Cross-thread data access; must go through Lock-protected get_web_usage() |
| monitoring_data dict → display callback | WebUsageData is an immutable frozen dataclass — safe to share across thread boundary without additional locking |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04-01 | Tampering | web_usage in monitoring_data | accept | WebUsageData is frozen dataclass — cannot be mutated after construction. Sharing across thread boundary is safe. |
| T-04-04-02 | Denial of Service | _web_poller not set | mitigate | `self._web_poller.get_web_usage() if self._web_poller else None` — None default prevents AttributeError when poller not registered. display_controller passes None to session_display which renders D-18 fallback. |
| T-04-04-03 | Information Disclosure | WebUsageData in display pipeline | accept | WebUsageData contains only utilization_pct (%), reset_at (datetime), fetched_at (datetime), plan_limit_tokens (None for Teams). No credentials, no PII. |
</threat_model>
