# Milestone v2.0: Web-Sourced Usage + System Tray

**Status:** ✅ SHIPPED 2026-05-19
**Phases:** 1–6 (v1.0: 1–3, v2.0 extensions: 4–6)
**Total Plans:** 23

## Overview

v2.0 extends the v1.0 terminal dashboard with authoritative usage data pulled from claude.ai via browser cookie authentication, a persistent color-coded system tray indicator, and per-project token breakdowns. `core/usage_fetcher.py` already existed — AUTH and WEBD extended it. Two net-new modules (`monitoring/web_poller.py`, `ui/tray_manager.py`) covered the new surface area.

**v1.0 (Phases 1–3)** delivered the Windows port, P90 threshold detection, and the overage pool dashboard.
**v2.0 (Phases 4–6)** delivered the claude.ai web integration, system tray, and per-project breakdown.

## Milestone Summary

**Key Decisions:**

- Fork reference tool (Maciek-roboblog/Claude-Code-Usage-Monitor) — avoids rebuilding JSONL reader, P90 calc, Rich UI from scratch
- P90 threshold with 10-session cold-start guard — statistically reliable, avoids false overage on first runs
- $500 pool size is configurable — user-editable in config.json without code changes
- Firefox-first cookie extraction; Chrome/Edge ABE (v127+) may block browser-cookie3; manual sessionKey paste is the guaranteed fallback
- WebPoller subclasses threading.Thread directly (daemon=True); Event.wait(300) loop; no join() in stop()
- TrayManager uses run_detached() + setup callback for race-free visible=True; CTRL_C_EVENT not SIGINT for cross-thread quit
- SSL verify=False for corporate SSL inspection proxy (matches existing urllib.request path)
- _col_pad() helper for Rich markup-aware column padding — f-string :<N breaks on markup tags and wide emoji

**Issues Resolved:**

- Cloudflare spike (2026-05-18): NOT blocking; urllib.request + httpx both work; curl_cffi NOT needed
- Chrome App-Bound Encryption: handled via Firefox-first priority order + keyring fallback
- Python 3.12 shim: find_module() silently removed; updated to find_spec()
- Column alignment with Rich markup + emoji: _col_pad() strips markup and accounts for east-Asian-width chars

**Issues Deferred:**

- ANLX-01: Historical daily pool spend chart — v2.1+
- ANLX-02: Overage pool balance from web API — v2.1+
- ALRT-01: Terminal bell at configurable pool % threshold — v2.1+
- Window toggle when launched inside existing shell — v2.1+ (ctypes GetConsoleWindow() returns outer shell HWND)

**Technical Debt:**

- session_key was in plaintext config.json (04-06 migrated it to keyring on first run)
- SSL verify=False on httpx calls — acceptable for corporate proxy but should be replaced with proper CA cert configuration in a future pass
- 05-VERIFICATION.md and 06-VERIFICATION.md marked human_needed at milestone close (acknowledged, deferred)
