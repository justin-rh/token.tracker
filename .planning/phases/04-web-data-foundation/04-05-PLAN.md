<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebUsageData → display rendering | Untrusted float (utilization_pct) and datetime (reset_at) rendered into Rich markup strings |
| kwargs dict → session_display | kwargs.get() used for all Phase 4 values — no KeyError possible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05-01 | Tampering | utilization_pct display value | mitigate | Rendered as `{:.1f}%` — formatted float, no string interpolation of raw API response. API value is already a float clamped by Python's float() cast in fetch_web_usage(). |
| T-04-05-02 | Denial of Service | negative delta in reset_at countdown | mitigate | `total_secs = max(0, int(delta.total_seconds()))` — floor at 0 prevents negative countdown display when reset_at is in the past. |
| T-04-05-03 | Tampering | Rich markup injection via utilization_pct | accept | utilization_pct is a float formatted with `:.1f` — no user-controlled string in markup. reset_at is formatted with strftime — no injection vector. |
| T-04-05-04 | Denial of Service | Calibrating + web_usage conflict | mitigate | `_show_threshold_rows` guard suppresses entire threshold block when web_usage is not None. Prevents "Calibrating" and "Utilization: X% via claude.ai" appearing simultaneously (Pitfall 7). |
</threat_model>
