       ```python
       def _setup_auth(config_dir: Path) -> tuple:
           """Resolve authentication before the Rich Live display starts.

           MUST be called BEFORE live_display.__enter__() — console input() is
           incompatible with the Rich Live rendering context (Pitfall 5 in RESEARCH.md).

           Returns (session_key, org_id). Either may be None if setup failed.
           Per D-01, D-02, D-04, D-06, D-08, D-09, D-11.
           """
           import json
           import keyring

           _migrate_config_to_keyring(config_dir)  # D-04: one-time migration

           # Read config.json for org_id
           config_file = config_dir / "config.json"
           try:
               cfg = json.loads(config_file.read_text(encoding="utf-8")) if config_file.exists() else {}
           except Exception:
               cfg = {}

           session_key, _cf = _read_auth_cookies(config_dir)  # D-06 priority order

           if not session_key:
               # D-08: No sessionKey available from keyring, Firefox, or Chrome
               # Block dashboard launch and prompt for manual paste
               print("\nWeb auth required.")
               print("1. Open claude.ai in your browser")
               print("2. Open DevTools (F12) → Application → Cookies → claude.ai")
               print("3. Copy the value of the 'sessionKey' cookie")
               print()
               try:
                   session_key = input("Paste sessionKey here: ").strip() or None
               except (EOFError, KeyboardInterrupt):
                   session_key = None
               if session_key:
                   try:
                       keyring.set_password("claude-monitor", "sessionKey", session_key)
                   except Exception as exc:
                       import logging
                       logging.getLogger(__name__).warning("auth: failed to store sessionKey in keyring: %s", exc)

           # D-01/D-02: org_id from config or auto-discovery
           org_id = cfg.get("org_id")
           if not org_id and session_key:
               # D-09: Attempt auto-discovery before prompting user
               org_id = _discover_org_id(session_key)
               if org_id:
                   # Write discovered org_id to config.json
                   cfg["org_id"] = org_id
                   try:
                       config_dir.mkdir(parents=True, exist_ok=True)
                       tmp = config_file.with_suffix(".tmp")
                       tmp.write_text(json.dumps(cfg, indent=2) + "\n", encoding="utf-8")
                       tmp.replace(config_file)
                   except Exception as exc:
                       import logging
                       logging.getLogger(__name__).warning("auth: failed to write org_id to config.json: %s", exc)
               else:
                   # D-09: Auto-discovery failed — prompt user
                   print("\nOrg ID required (auto-discovery failed).")
                   print("Find it in: claude.ai → Settings → Account → Organization ID")
                   print()
                   try:
                       org_id = input("Paste org_id here: ").strip() or None
                   except (EOFError, KeyboardInterrupt):
                       org_id = None
                   if org_id:
                       cfg["org_id"] = org_id
                       try:
                           config_dir.mkdir(parents=True, exist_ok=True)
                           tmp = config_file.with_suffix(".tmp")
                           tmp.write_text(json.dumps(cfg, indent=2) + "\n", encoding="utf-8")
                           tmp.replace(config_file)
                       except Exception as exc:
                           import logging
                           logging.getLogger(__name__).warning("auth: failed to write org_id to config.json: %s", exc)

           return session_key, org_id
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| console input → keyring storage | User-pasted sessionKey received via input(); stored in Windows Credential Manager |
| config.json → org_id | org_id read from config.json; must be a valid UUID format for URL construction |
| sessionKey in input() → keyring | sessionKey string should not appear in any log after this point |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06-01 | Information Disclosure | sessionKey via input() | mitigate | input() on a terminal does not echo to log files. After reading, sessionKey is passed to keyring.set_password() — not concatenated into log strings. _setup_auth() uses logger.warning() only for exception messages (no key value in format string). |
| T-04-06-02 | Spoofing | org_id from config.json | accept | org_id is a UUID read from user-controlled config.json. It is formatted into the API URL. A malformed org_id causes an HTTP 404 — no server-side execution. The URL is fixed-prefix (claude.ai) so org_id injection cannot redirect to a different host. |
| T-04-06-03 | Tampering | console prompt before Rich Live | mitigate | Auth setup explicitly runs before `live_display.__enter__()` (Pitfall 5). Acceptance criteria includes grep check that _setup_auth call appears above the __enter__ line. |
| T-04-06-04 | Denial of Service | WebPoller not stopped on exit | mitigate | `finally: if "web_poller" in locals() and web_poller is not None: web_poller.stop()`. Additionally, daemon=True means the thread dies with the process even if finally block is skipped. |
| T-04-06-05 | Information Disclosure | org_id in logs | mitigate | _setup_auth() does not log the discovered org_id UUID. It logs "auth: failed to write org_id" (error path) without including the value. |
| T-04-06-06 | Elevation of Privilege | sessionKey stored in keyring accessible to other apps | accept | Windows Credential Manager entries are user-scoped — accessible to any process running as the same Windows user. This is the intended behavior (AUTH-03: persists across restarts). Acceptable for a local developer tool. |
| T-04-06-07 | Information Disclosure | Billing cycle reset log | accept | D-24 log line "Billing cycle reset — pool spend cleared to $0.00" contains no credentials or user data. Dollar amount is hardcoded string. |
</threat_model>
