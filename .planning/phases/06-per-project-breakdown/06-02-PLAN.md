```python
def _derive_billing_cycle_start(cycle_day: int) -> date:
    today = date.today()
    try:
        if today.day >= cycle_day:
            return today.replace(day=cycle_day)
        else:
            if today.month == 1:
                return today.replace(year=today.year - 1, month=12, day=cycle_day)
            else:
                return today.replace(month=today.month - 1, day=cycle_day)
    except ValueError:
        logger.warning("billing_cycle_start_day=%r caused date error — using day 1", cycle_day)
        return today.replace(day=1)
```

**Public function:**

```python
def compute_project_breakdown(
    data_path: Optional[Path] = None,
    config_dir: Optional[Path] = None,
) -> ProjectBreakdown:
```

Algorithm:
1. Apply defaults for data_path and config_dir.
2. Read cycle_day via `_read_cycle_day(config_dir)`.
3. Compute `billing_start: date = _derive_billing_cycle_start(cycle_day)`.
4. Compute `today_date: date = datetime.now(timezone.utc).date()`.
5. Accumulate `today_tokens: dict[str, int]` and `month_tokens: dict[str, int]` keyed by display_name.
6. For each file_path in `_find_jsonl_files(data_path)`:
   a. Extract `slug = file_path.parent.name` and `display_name = slug.split("-")[-1]`.
   b. Parse all lines into `raw_entries: list` using utf-8-sig + json.loads; skip blank/malformed lines.
   c. PermissionError → logger.warning + continue (skip file).
   d. Any other Exception → logger.warning + continue (skip file, not fatal).
   e. `entries = _deduplicate_entries(raw_entries)`.
   f. For each entry in entries:
      - Parse timestamp (fromisoformat; force UTC if tzinfo is None). If parse fails → continue.
      - Compute `total = input_tokens + output_tokens + cache_creation_input_tokens + cache_read_input_tokens` (all via `.get("message", {}).get("usage", {}).get(key, 0)`).
      - If total == 0: skip (zero-token entries excluded).
      - If `ts.date() == today_date`: `today_tokens[display_name] += total`.
      - If `ts.date() >= billing_start`: `month_tokens[display_name] += total`.
7. Sort each dict by value descending, take top 5, build list of (name, tokens) tuples.
8. Return `ProjectBreakdown(today=today_top5, billing_month=month_top5, as_of=datetime.now(timezone.utc))`.

**Filtering rules:**
- Exclude projects with 0 total tokens from both lists.
- `data_path.rglob("*.jsonl")` may return statusline.jsonl — the parent directory of statusline.jsonl is `.claude` (not a project slug), so its display_name will be `.claude`. This is harmless; it will appear in the list only if it has token entries (unlikely). No special exclusion needed.

**Performance:** Called every 10s from the monitoring cycle. This is acceptable — the JSONL scan is the same scan already done by data/reader.py on the same cycle. No caching needed in Phase 6.
