<objective>
Fix the display-name collision log level in project_breakdown.py (QUAL-02).

Purpose: When two project directories share the same last slug segment (e.g., both "foo-tracker"
and "bar-tracker" map to display name "tracker"), the collision is currently logged at DEBUG level
with only one slug identified. This is silent to users running at the default WARNING log level.
The fix bumps to WARNING and includes BOTH colliding slugs so the user can identify which projects
are affected.

Output:
- `project_breakdown.py`: `slug_map: dict[str, str]` local variable tracks first-seen slug per
  display_name; collision log becomes `logger.warning(...)` with both slugs interpolated
- `test_project_breakdown.py`: new test verifies WARNING is logged with both slug names
</objective>
